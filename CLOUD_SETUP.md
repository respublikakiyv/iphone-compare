# Постоянная работа без Mac

Проект подготовлен для одного постоянно работающего Docker-сервиса в Railway.
Он запускает bot.py и sync_agent.py, читает общую очередь Mini App и отправляет
обновления по HTTPS. Mac после переноса не нужен. Интерфейс и серверная база
остаются по прежнему адресу. Цена размещения зависит от тарифа и потребления.

## Развёртывание

1. Подключите Railway в ChatGPT и выберите свой проект/аккаунт для размещения.
2. Разверните содержимое iphone-compare как один сервис из Dockerfile.
3. Добавьте постоянный Volume с точкой монтирования /app/data. SQLite,
   блокировка запуска и pending_publication.json должны переживать перезапуски.
4. Добавьте секреты TELEGRAM_BOT_TOKEN и SYNC_WORKER_KEY. Последний обязан
   совпадать с серверным ключом Mini App. В архив секреты не включены.
5. Добавьте MINIAPP_URL=https://iphone-price-miniapp.greydrake2.chatgpt.site
   и ENABLE_MINIAPP=1. SITES_SERVICE_TOKEN не нужен для публичного приложения.
6. Используйте одну реплику, отключите сон сервиса. ALWAYS требует подходящего
   платного тарифа. Перед облачным запуском остановите Start.command на Mac:
   два polling-процесса одного Telegram-бота конфликтуют.
7. Дождитесь логов Telegram authenticated и Mini App menu configured.
8. При выключенном Mac откройте Telegram, измените курс, скопируйте карточку,
   нажмите обновление цен. Проверьте завершение задания и время проверки цен.

Обновление полного каталога проверяется отдельно. HTTP 403/429 магазинов не
обходятся. При отказе сохраняется последняя подтверждённая цена с датой.
Полноценная проверка доступности магазинов с IP облачного сервера обязательна.

## Telegram-канал

В закреплённом сообщении канала разместите ссылку на бота
https://t.me/Check_priceipeople_bot. Пользователь открывает его и нажимает
«Открыть приложение». Для прямой ссылки на Main Mini App настройте её через
BotFather и используйте подтверждённую Telegram ссылку. Telegram сам не
исполняет Python: процесс работает в облачном сервисе.

## Статус подготовки

Dockerfile и конфигурация подготовлены. Сам облачный сервис ещё не создан:
требуется подключение аккаунта хостинга. Docker-сборка и доступ магазинов
с его IP не проверены в текущей среде.

## Render (альтернатива Railway)

render.yaml описывает один Docker Background Worker и постоянный диск 1 GB.
Создайте Blueprint из репозитория с этой папкой в корне. TELEGRAM_BOT_TOKEN
и SYNC_WORKER_KEY вводятся как секреты при создании. Значения в архиве
отсутствуют. Процесс не обслуживает веб-порт: выбирайте Background Worker,
а не Web Service. Интерфейс Mini App остаётся на прежнем HTTPS-адресе.

Перед запуском: проверить тариф/стоимость worker и диска, остановить bot/worker
на Mac. После запуска: проверить логи, обновление цен и полного каталога из
Telegram при выключенном Mac. Сервис Render в текущем сеансе не создан:
доступ к аккаунту должен быть подключён отдельно. Наличие render.yaml не
означает, что бот уже перенесён или что подписка хостинга оплачена.
